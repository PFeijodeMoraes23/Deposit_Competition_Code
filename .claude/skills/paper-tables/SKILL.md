# Tables and figures for the paper

## The fix goes in the generator

Every `.tex` exhibit is regenerated by a script, so a hand edit is overwritten on the next run and
breaks reproducibility. To change an exhibit: find its generator (search the repo for the output
filename), change the generator, re-run it, and check the result. `V_Main.tex` is never edited,
and neither is the deck: when the prose or a slide has to change, give the user paste-ready lines.

Generators checked by their own headers:

| Exhibit | Generator |
|---|---|
| Descriptive tables, Figure 1, the variables master | `make_desc_panel_tables.py`, `make_desc_compressed_tables.py` |
| Sleepiness tables | `sleep_export_all.py`, `sleep_export_spec12_compare.py`; notes from `utils/sleep_notes.py` |
| Cluster imbalance | `sleep_desc_clusters.py` |
| Logit table | `blp_logit.jl` |
| BLP tables | `make_blp_demand_comparison_table.py`, `make_blp_rc_table.py` |
| Policy-function tables (`polfunc_k4`, `polfunc_k5`) | `bbl_polfunc.py --from-pkl` |
| BBL cost tables and the ratio figure | `make_bbl_cost_tables.py`, `make_bbl_ratio_figure.py` |
| Numbers the prose quotes | `make_paper_numbers.py` |
| Equations and labels for decks | `make_paper_equations.py` |
| Slide visuals | `make_slide_figures.py` |

Edit code that carries LaTeX with the Edit or Write tool. A bash heredoc collapses `\\` and has
turned `\b` into a backspace character in these files.

## Displayed numbers

- Three decimals for every displayed number: coefficients, standard errors, interval bounds,
  means, shares, statistics such as G* or Q, and numbers inside the notes.
- Integers with thousands separators for observations, counts (clusters, firms, markets, draws)
  and levels: R$ values, deposit volumes, HHI on the 0 to 10,000 scale, GDP per capita, population.
- Never print −0.000.
- A nonzero value that would print as 0.000 is flagged to the user. Do not rescale units to dodge
  it. `make_bbl_cost_tables.py` lists such cells on stdout under `ZERO_PRINTS`. Switching a row or
  table to basis points is the user's decision; it has been taken for the Basel row of the
  cost-parameter table and for the whole prepaid policy-function table (`polfunc_k5`), with the
  unit stated.
- Stars come from the unrounded values, so an interval bound may print 0.000 beside a star.

## Units and annualization

- Table notes and labels write "pp" and "bp". The paper's prose defines both at first mention.
- Annualize by compounding, never by ×4 or ×400. A rate level is ((1 + x_q)^4 − 1) × 100. A spread
  is 100 × [(1 + r^f_q)^4 − (1 + r^dep_q)^4]; the panel's `spread_ann_a{k}` is that object as a
  fraction. A coefficient from a linear model cannot be compounded: show it per quarter, or
  re-estimate on the compounded variable.
- Check a unit conversion with an identity to about 1e-12. A correlation of 0.999 once hid a level
  gap of 6 percent between simple and compounded spreads.
- Display units of the sleepiness state variables come from `utils/state_transform.py`, the one
  registry. Do not restate a scale factor in a generator.

## Inference shown in tables

- One scheme per table: the wild cluster bootstrap by conglomerate (Webb weights, B = 999), in the
  linear and the nonlinear columns alike. G* is reported as a diagnostic.
- Pix and the lagged Selic are national regressors. Their reported cell is the quarter-clustered
  wild bootstrap, marked †, chosen row by row through `utils/se_national.py` (`select_se`,
  `national_note`). Never report the larger of two schemes cell by cell: the columns of one row
  would then differ in scheme as well as in estimator. Driscoll and Kraay appears only as a
  bracketed line on the all-linear tables.
- The marginal effect of a 0/1 regressor is a discrete difference, not a derivative.
- Whiskers on a coefficient plot use the table's own critical value, Student-t at G*, not 1.96.
- To override a fitted statsmodels result's standard errors, set `res._results._cache[name]`.
  Writing to `__dict__` does nothing, silently.

## Notes, labels and cross-references

- Build notes from the shared helpers (`utils/sleep_notes.py`, `national_note`) so one wording
  serves every table that needs it.
- Routine names come from `config/routines.toml` (`tex_name`, `tex_ref`). A routine is cited as
  `\ref{estimation:...}`, and a table as `\ref{tab:...}`: typed "(III)" or "Table 4" goes stale
  whenever the paper renumbers.
- The reported routine set of the cost tables is `link_ests`. To show other routines, add a
  `--routines` flag to the generator; do not widen `link_ests`.

## Layout

- A table that fits on one page must not split: use the non-breaking layout,
  `_wrap(..., nobreak=True)` in `make_bbl_cost_tables.py` (a minipage with `\captionof` and
  `tabularx`). `xltabular` is only for tables longer than a page.
- B and D columns sit side by side in portrait, B on the left. Landscape was turned down.
- Caption, label and notes live inside the generated file, in the paper's house style.

## Numbers in the prose and on slides

- Every number the prose quotes is a key in `make_paper_numbers.py` and is printed with
  `\pn[fmt]{key}`: `\pn{key}` gives three decimals or an integer count, `[0-3]` sets decimals,
  `[a<d>]` the absolute value, `[p<d>]` one hundred times the value, `[w]` the value in words.
- Prefer an unrounded sidecar written by the table's generator. A value parsed from a rendered
  table is flagged `rounded3`, and the macro refuses a coarser rounding when the third decimal is 5.
- Every slide visual comes from `make_slide_figures.py`, and no number is typed there either.
  Panels shared with the paper reuse the paper figure's drawing functions.

## Code comments in generators

Describe what the code does now and the measured fact that justifies it. Do not narrate what it
replaced ("legacy", "used to be", a date of change); that history is in version control.

## Verifying a change

1. Re-run the generator with `C:/venvs/egan/Scripts/python.exe` and read its stdout.
2. Compare the new file with the previous one: only the intended cells should differ. For a pure
   layout change, the multiset of numbers must be identical.
3. Compile a scratch copy of the paper, or a minimal harness, and check for overfull boxes and that
   a one-page table stayed on one page. With `-output-directory`, pdflatex still reads the source
   folder's `.aux`; if TeXstudio is mid-build the first pass can die at `\begin{document}`, so
   retry before suspecting the table.
4. If a quoted number moved, re-run `make_paper_numbers.py` (the `post-run-refresh` skill gives
   the order) and tell the user which sentences now disagree with the table.
